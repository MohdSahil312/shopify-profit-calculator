# Shopify Profit Calculator

**Built with Next.js 16 + Tailwind CSS v4**

## 🚀 Getting Started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## ⚙️ Customization

Before deploying, update your personal info in `app/page.tsx`:

1. Find the `<footer>` section near the bottom of the file
2. Replace `Your Name` with your actual name
3. Replace `your@email.com` with your email address

## 📊 Features

- **5 Inputs**: Selling price, product cost, shipping, ad spend, gateway fee %
- **Live Metrics**: Revenue, total cost, net profit, profit margin, ROI, gateway fee
- **Cost Breakdown Bar**: Visual stacked bar showing cost distribution
- **Quick Presets**: Low / Mid / High ticket product presets
- **Smart Tips**: Contextual advice based on margin health
- **Mobile Responsive**: Stacks to single-column on mobile
- **Dark SaaS UI**: Glassmorphism, gradient accents, animated elements

## 🛠 Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS v4
- **Font**: Geist (via `next/font/google`)
- **Language**: TypeScript
